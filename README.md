# It's a cross-platform tree/forest simulator program written in C++, CMake, and deployed via Qt. You can see the evolution of trees! 
## If running on Linux, you may want to install the latest 6. release.

### You can download our program from Github, under the releases tab. It is available for windows and Linux. You only have to choose a version, download it, and it's ready to go.
---
#### Functions:
- You can resize the simulation's area,
- You can start/stop the simulation,
- It is possible to change themes, (5)
- You can see:
    - the number of trees,
    - the simulation's age,
- Reset the simulation,
- (not yet: ) set where trees start to generate (should add an MIT license?)
